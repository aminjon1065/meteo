## 6. Процесс

- Репозиторий: GitHub (private), trunk‑based, PR с обязательным CI (lint, typecheck, unit, e2e smoke, build), conventional commits, автогенерация CHANGELOG.
- Еженедельный отчёт Заказчику (п. 4 контракта) — пятница, из CHANGELOG + статусы вех + блокеры; демо на staging по вехам.
- Definition of Done для задачи: код + тесты + перевод на 3 языка + документация (если меняет поведение для пользователя) + прошла проверка доступности для UI + задеплоено на staging.
- Качество: unit ≥ 80 % для `core` (индекс, QC, CAP, SILAM); e2e для 12 ключевых сценариев; Lighthouse‑бюджеты; `pnpm audit`/Trivy без критичных.
- Секреты и доступы — в менеджере паролей Исполнителя, передача Заказчику по акту.
