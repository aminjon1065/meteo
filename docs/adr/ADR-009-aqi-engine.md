# ADR-009: Движок индекса качества воздуха — табличный, три шкалы

**Status:** Accepted (16.10.2026) · **Date:** 2026-10-16

## Context
ТЗ требует национальный индекс по 6 веществам, опционально AQI по ВОЗ, пятиуровневую шкалу PM2.5 с цветами и рекомендациями; пороги должны настраиваться в админке. Национальная методика не предоставлена; в регионе исторически используется ИЗА (РД 52.04.186‑89) и ПДК.

## Decision
Чистый модуль `packages/core/aqi` с тремя стратегиями: `breakpoints` (оперативный 5‑уровневый индекс, seed — пороги финского индекса FMI), `ratio_to_limit` (кратность ПДК) и `iza` (комплексный ИЗА по среднемесячным). Все пороги, ПДК, классы опасности, цвета и подписи — в БД, редактируются администратором, версионируются через аудит. Индекс станции = максимум под‑индексов; предрасчёт в `station_index`.

## Options Considered
| Вариант | Итог |
|---|---|
| A. Табличный движок, 3 стратегии (выбрано) | Любая национальная методика ложится без релиза; тестируемо |
| B. Одна захардкоженная шкала (например, US EPA AQI) | Не соответствует «национальному индексу», требует релиза при изменении |
| C. Только ВОЗ | Не покрывает ИЗА/ПДК, к которым привыкла служба |

## Consequences
- Проще: согласование с Заказчиком сводится к заполнению таблиц; страница «Об индексе» генерируется из тех же данных.
- Сложнее: нужно объяснить пользователю, какая шкала показана (переключатель и подпись).
