# ADR-003: Карты — MapLibre GL JS + self‑hosted PMTiles

**Status:** Proposed · **Date:** 2026-10-16

## Context
Интерактивная карта с кластерами станций, растровым слоем SILAM, полигонами CAP, границами регионов, ползунком времени. Медленный интернет в регионах, запрет российских сервисов (п. 10.2 контракта), отсутствие бюджета на платные тайлы, желание независимости от внешних сервисов.

## Decision
MapLibre GL JS (векторные тайлы) + базовая карта Protomaps в формате PMTiles (экстракт Таджикистана с окрестностями, ~100–150 МБ) на нашем Caddy; стиль с подписями ru/en из OSM и нашими tg‑подписями городов из БД. Границы — GeoJSON из PostGIS (упрощённые). SILAM — `image`‑источник.

## Options Considered
| Вариант | Complexity | Cost | Независимость | Итог |
|---|---|---|---|---|
| A. MapLibre + PMTiles self‑hosted (выбрано) | Med | 0 USD/мес | Полная | Один файл тайлов, нет лимитов |
| B. Leaflet + публичные растровые тайлы OSM | Low | 0 | Нет (политика OSM запрещает прод‑нагрузку) | Риск блокировки |
| C. MapTiler/Mapbox cloud | Low | 50–500 USD/мес | Нет | Платно, внешняя зависимость |
| D. Google/Yandex Maps | Low | Лицензии | Нет; Яндекс исключён контрактом | Отклонено |

## Consequences
- Проще: офлайн/интранет‑работа, стабильная стоимость, тёмная тема стилем.
- Сложнее: сборка экстракта PMTiles и обновление раз в полгода (скрипт в `infra/data`).
