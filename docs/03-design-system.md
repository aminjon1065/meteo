# 03. UX/UI и дизайн‑система

## 1. Принципы продукта

1. **Ответ за 3 секунды.** Главный вопрос посетителя: «Каким воздухом я дышу сейчас и что делать?» Ответ — в первом экране: уровень, цвет, одно действие.
2. **Цвет никогда не единственный носитель смысла.** Уровень = цвет + подпись + иконка + число. Карта и графики имеют текстовые альтернативы.
3. **Честность данных.** Всегда видно «когда обновлено», откуда данные, какой флаг качества; устаревшие данные помечаются.
4. **Три языка — равноправны.** Таджикский по умолчанию; длина строк в tg/ru до 30 % больше en — компоненты переносят текст, а не обрезают.
5. **Медленная сеть — норма.** Контент читается до загрузки карты; карта и графики — прогрессивно.

## 3. Информационная архитектура (публичная часть)

Маршруты локализованы: `/…` (tg), `/ru/…`, `/en/…`; slug'и новостей — на каждом языке свои.

| Маршрут | Содержание |
|---|---|
| `/` Главная | Hero: выбранный город (по умолчанию Душанбе, запоминается) — индекс (цифра + уровень + цвет), доминирующее вещество, обновлено N мин назад, 1 рекомендация; полоса активных предупреждений; компактная карта станций; «Погода сегодня» по 6–8 городам (SmartMet); «Качество воздуха завтра» (SILAM); 3 последних новости; подписка |
| `/air` Качество воздуха | Карта + список станций (сортировка по индексу/региону), легенда шкалы, переключатель шкалы (национальная / ВОЗ) |
| `/air/stations/{slug}` Станция | Текущий индекс и под‑индексы по веществам (плитки), график с табами 24 ч / 7 дн / 30 дн / 1 год и полосами уровней, выбор вещества, скачать CSV, рекомендации для текущего уровня (табы по группам), прогноз SILAM для точки, паспорт станции, карта‑миниатюра |
| `/air/index` Об индексе | Методика: национальный индекс, шкала ВОЗ, таблицы порогов (из БД), как читать цвета |
| `/health` Здоровье | Рекомендации по 5 уровням × 6 групп; печатная версия |
| `/map` Карта | Полноэкранная: слои (станции, SILAM по веществам, предупреждения, границы областей/районов, опционально WMS SmartMet), ползунок времени, кластеризация, попапы с переходом на станцию, легенда, геолокация |
| `/weather` Погода | Список городов/районов с символом и температурой; `/weather/{slug}` — почасовой прогноз на сегодня/завтра, суточный на 7–10 дней, ветер, осадки, влажность; предупреждения для региона |
| `/warnings` Предупреждения | Активные по дням (сегодня/завтра/послезавтра) и регионам, карта с полигонами, детали CAP (headline, описание, инструкция, период), архив |
| `/news`, `/news/{slug}` | Лента по рубрикам, статья с OG‑изображением; `/newsletters` — архив бюллетеней |
| `/subscribe`, `/confirm`, `/unsubscribe` | Подписка на уведомления и бюллетень (double opt‑in) |
| `/data` Открытые данные | Описание API, примеры, CSV, лицензия данных |
| `/about`, `/contacts` | О портале, FINTAJ, FMI, Агентство |
| `/embed/{forecast|alerts|aqi}` | Виджеты для meteo.tj (без шапки, с параметрами `location`, `lang`, `theme`) |

Навигация: десктоп — верхняя панель (логотип, 6 разделов, поиск города, язык); мобильный — нижняя панель из 5 пунктов (Главная, Воздух, Карта, Погода, Предупреждения) + меню.

## 5. Дизайн‑токены

### Цвета (CSS‑переменные, светлая/тёмная тема)

| Токен | Светлая | Назначение |
|---|---|---|
| `--primary` | `#0E5EA8` (глубокий небесно‑синий) | Кнопки, ссылки, активные состояния |
| `--primary-fg` | `#FFFFFF` | Текст на primary |
| `--accent` | `#F2994A` (тёплый) | Редкие акценты, CTA подписки |
| `--bg` / `--surface` / `--surface-2` | `#F6F8FB` / `#FFFFFF` / `#EEF2F7` | Фон, карточки |
| `--fg` / `--fg-muted` | `#0F172A` / `#475569` | Текст |
| `--border` | `#D9E1EC` | Разделители |
| `--focus` | `#2563EB` | Кольцо фокуса (2 px, видимое всегда) |

Семантическая шкала качества воздуха (одна на весь продукт, с контрастным текстом):

| Уровень | Токен | Цвет | Текст на нём |
|---|---|---|---|
| 1 Хороший | `--aq-1` | `#2E9E5B` | белый |
| 2 Удовлетворительный | `--aq-2` | `#E3B505` | тёмный |
| 3 Умеренный | `--aq-3` | `#F28C28` | тёмный |
| 4 Плохой | `--aq-4` | `#D7263D` | белый |
| 5 Очень плохой | `--aq-5` | `#7B2CBF` | белый |
| Нет данных | `--aq-0` | `#9AA5B1` | белый |

Серьёзность CAP: `--warn-minor #F2C94C` (жёлтый), `--warn-moderate #F2994A` (оранжевый), `--warn-severe #EB5757` (красный), `--warn-extreme #8B0000`.

Каждая категория дополняется иконкой (лицо/облако) и штриховкой на карте для дальтоников; проверка контраста ≥ 4,5:1 для текста, ≥ 3:1 для крупного текста и иконок.

### Типографика

- Шрифт: **Inter** (variable, self‑hosted через `next/font`), покрывает кириллицу с таджикскими буквами Ғ Ӣ Қ Ӯ Ҳ Ҷ; фолбэк `system-ui`. Табличные цифры (`font-variant-numeric: tabular-nums`) для значений.
- Шкала: 12 / 14 / 16 (базовый) / 18 / 20 / 24 / 32 / 40 / 56 (hero‑число индекса). Межстрочный интервал 1,5 для текста, 1,2 для заголовков.
- Числа и даты через `Intl` по локали (tg/ru — десятичная запятая, en — точка); единицы всегда рядом со значением (`µg/m³`, `mg/m³`, `°C`, `м/с`).

### Сетка, отступы, формы

- Сетка 4 px; контейнер 1280 px; брейкпоинты 640 / 768 / 1024 / 1280.
- Радиусы 8 (элементы) / 12 (карточки) / 999 (бейджи). Тени мягкие двухслойные. Границы 1 px.
- Анимации ≤ 200 мс, уважение `prefers-reduced-motion`.

## 7. Ключевые экраны (описание вайрфреймов)

**Главная (мобильная):** [Шапка: логотип, язык] → [Полоса предупреждений, если есть] → [AqiHero: «Душанбе · сейчас» · 4 · Плохой · PM2.5 68 µg/m³ · обновлено 10 мин назад · «Сократите время на улице, уязвимым группам — остаться дома» · кнопка «Рекомендации»] → [Карта 240 px с кластерами, кнопка «Открыть карту»] → [Горизонтальный скролл ForecastCard по городам] → [«Завтра» SILAM: 3 плитки городов с уровнем] → [3 новости] → [Подписка: e‑mail + станция] → [Футер: Агентство, FMI/FINTAJ, API, языки].

**Страница станции:** заголовок (название, регион/район, статус, FreshnessBadge) → AqiHero → ряд PollutantTile → TimeseriesChart с табами периода и селектором вещества, кнопка CSV → HealthAdvice (по текущему уровню) → SILAM‑прогноз на 3 дня (мини‑график) → паспорт станции + мини‑карта.

**Карта:** слева панель слоёв (на мобильном — нижний sheet), снизу TimeSlider (появляется при включении SILAM/предупреждений с временем), справа легенда; попап станции: индекс, 3 вещества, «открыть».

**Админка → Ввод измерений:** выбор станции и даты → сетка (строки — часы проб 01/07/13/19 или произвольные, столбцы — вещества), подсветка невалидных ячеек, «сохранить», «отправить на QC»; справа панель последних значений для сверки.

**Админка → QC:** список подозрительных значений с фильтрами → карточка: график ±48 ч с выделенной точкой, правила, которые сработали → «подтвердить», «скорректировать» (новое значение + причина), «отклонить».

## 8. Доступность (WCAG 2.1 AA)

- Семантическая разметка, заголовки по порядку, `lang` на `<html>` и на фрагментах другого языка.
- Фокус видим всегда; порядок табуляции логичен; все действия доступны с клавиатуры (в т. ч. ползунок времени, слои карты).
- Карта: альтернативный список станций с теми же данными; маркеры — кнопки с `aria-label`.
- Графики: скрытая таблица данных, `aria-describedby` с кратким резюме (мин/макс/среднее).
- Формы: подписи, ошибки текстом рядом с полем, `aria-invalid`, автосохранение.
- Контраст и размер касания ≥ 44 px; `prefers-reduced-motion`, `prefers-color-scheme`.
- Проверки: axe в Playwright‑тестах, ручной прогон со скринридером (VoiceOver/NVDA) перед сдачей.

## 9. Контент и локализация

- Словарь терминов (tg/ru/en) ведётся в `packages/i18n/GLOSSARY.md`: вещества, уровни, группы, типы предупреждений; валидируется носителем языка (D10).
- Ключи сообщений типизированы; отсутствующий перевод падает в CI (lint‑правило), а не показывает ключ пользователю.
- Даты/время: локальное `Asia/Dushanbe` с явным указанием пояса в выгрузках (столбцы `time_utc`, `time_local`).
- Тон текстов рекомендаций: короткие императивы, без медицинского жаргона; черновики для 5 × 6 ячеек готовим мы, подтверждают эксперты Заказчика (D7).

## 10. SEO и соцсети

- `generateMetadata` на каждой странице, `hreflang` для 3 локалей, канонические URL, `sitemap.xml` (с новостями и станциями), `robots.txt`.
- OG‑изображения генерируются динамически (`ImageResponse`): для станции — текущий уровень и цвет; для новости — обложка + заголовок.
- JSON‑LD: `Organization`, `NewsArticle`, `Dataset` для станций (открытые данные).

## 11. Производительность интерфейса

- Критический путь главной — только HTML/CSS + минимальный JS; карта и графики — `dynamic()` с загрузкой по видимости.
- Изображения через `next/image` (AVIF/WebP, размеры по брейкпоинтам); иконки — SVG‑спрайт.
- Кэш клиента: TanStack Query с `staleTime` 60 с; `prefetch` соседних кадров SILAM.
- PWA‑манифест и иконка «на главный экран» (офлайн‑режим — вне ТЗ, возможное расширение).
