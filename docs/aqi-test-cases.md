# Контрольные примеры индекса качества воздуха (приёмка M1)

Версия 1.0 · 02.11.2026 · к чек‑листу M1 (`docs/04-delivery-plan.md` §4) и ADR‑009.

Таблицы ниже — входные значения и уровень, который должен показать портал при **настройках по
умолчанию** (seed): пороги шкал (`packages/db/src/seed.ts`, разделы 2–3) и ПДК из ежедневного
бюллетеня Агентства от 19.10.2026. Все примеры проверяются автоматически тестом
`packages/core/src/__tests__/aqi-acceptance.test.ts`: если изменить пример здесь, а не в тесте
(или наоборот), тест упадёт. Если Агентство изменит пороги в админке, ожидаемые уровни меняются
вместе с ними — примеры описывают поставку по умолчанию.

Правила, общие для всех шкал:

- интервалы полуоткрытые: значение, равное нижней границе уровня, относится к этому уровню
  (PM2.5 = 10 — уже уровень 2, 9,9 — ещё уровень 1);
- индекс станции — худший из под‑индексов веществ, это вещество показывается как определяющее;
- в расчёт идут только значения с флагами «валидное» и «исправленное», не старше 6 часов;
- единицы — µg/m³, CO — mg/m³ (единица хранения; в настройках портала можно показывать mg/m³,
  на уровень это не влияет).

## Как проверить на портале

1. В админке создать тестовую станцию (`/admin/stations/new`) с нужным веществом, режим —
   непрерывные измерения.
2. В «Ручном вводе» (`/admin/measurements/entry`) ввести значение за прошедший полный час
   (для CO — восемь часовых значений подряд, для суточных шкал — 24).
3. Через 10 минут (задача `index-compute`) или сразу после ввода — уровень на странице станции и
   в API: `GET /api/v1/index/current?scale=<код шкалы>`.
4. После проверки вывести тестовую станцию из эксплуатации.

## 4. Кратность ПДК (`RATIO_TO_LIMIT`) и показатели бюллетеня Агентства

Кратность = среднесуточная концентрация / ПДКс.с., округление до сотых. Интервалы уровней:
< 1 — 1, 1–2 — 2, 2–3 — 3, 3–5 — 4, ≥ 5 — 5.

|---|---|---|---|

## 5. ИЗА (`IZA`, РД 52.04.186‑89)

По среднемесячным концентрациям: ИЗА = Σ (C / ПДКс.с.)^k, k = 1,7 / 1,3 / 1,0 / 0,9 для классов
опасности 1–4; учитываются пять наибольших слагаемых. Уровни: < 5 — низкий (1), 5–7 — повышенный
(2), 7–14 — высокий (4), ≥ 14 — очень высокий (5).

| № | Значения | Расчёт | Уровень |
|---|---|---|---|
| I1 | PM2.5 70 + PM10 120 + O₃ 60 | 2 + 2 + 3,25 = 7,25 | 4 (O₃) |

O₃ — 1 класс опасности: (60/30)^1,7 ≈ 3,25.
