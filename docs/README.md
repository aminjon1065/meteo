# Метеопортал FINTAJ — проектная документация

Проект: публичный метеопортал и система мониторинга качества воздуха для Агентства по гидрометеорологии Республики Таджикистан (Таджикгидромет) в рамках финско‑таджикского проекта FINTAJ (донор — Финский метеорологический институт, FMI).

Основание: контракт 06102026_68673 от 06.10.2026, Приложение 1 «Техническая спецификация, график и стоимость работ». Срок действия контракта — до 31.12.2026. Бюджет — 25 792 USD с НДС.
