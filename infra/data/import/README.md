# Примеры маппинга для импорта исторических данных

- `mapping-wide.example.json` — журнал поста наблюдений: дата и срок отбора в отдельных столбцах,
  столбец на каждое вещество, газы в мг/м³ (конвертируются в единицы справочника).
- `mapping-long.example.json` — «длинная» выгрузка (станция, время, вещество, значение, единица)
  с синонимами названий веществ; значения остаются «сырыми» (`qcFlag: 0`) и проходят автоконтроль.
- `sample-wide.csv` — пример файла для широкого маппинга (станция E2E-DU-01 есть только в базе E2E).

Запуск и описание всех полей маппинга — `docs/import-history.md`.
